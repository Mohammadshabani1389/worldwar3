# World War 3 Bot

- هر گروه تلگرام یک کشور است.
- اولین عضو گروه که «شروع بازی» می‌فرستد، نام کشور را انتخاب می‌کند.
- نام کشور در کل بازی تکراری نیست.
- همان شخص رهبر کشور می‌شود و نام رهبر از نام نمایشی تلگرام او گرفته می‌شود.
- هر شخص در یک قاره فقط یک کشور دارد؛ بنابراین اعضای مختلف یک قاره می‌توانند کشورهای جداگانه داشته باشند.
- کشور ساخته‌شده به‌صورت خودکار کشور پیش‌فرض سازنده می‌شود.
- در پیوی، «مرکز فرماندهی» روی کشور پیش‌فرض کار می‌کند.
- /start تنها دستور اسلشی فعلی است.

## شروع بازی
داخل گروه بنویسید:
`شروع بازی`

اگر گروه کشور نداشته باشد، ربات نام کشور را می‌خواهد.

## مرکز فرماندهی
در پیوی:
`مرکز فرماندهی`

هزینه ارتقا: پول + فلز + سوخت.

## Owner / Admin security

Set the permanent Owner Telegram numeric ID in `.env`:

`OWNER_ID=123456789`

`/owner` is available only to this ID. The Owner is also treated as Admin and normal User, but is never stored as a removable Admin. `/admin` is available to Admins and Owner. Admin add/remove/search uses Telegram numeric IDs only.

## ENIGMA

سامانه ENIGMA به‌صورت مستقل از مکانیک جنگ پیاده‌سازی شده است. چهار دسته فعال اولیه شامل جابه‌جایی حروف، مورس، حفظ چند اطلاعات و حفظ اطلاعات در متن هستند. بانک اولیه ۲۰۰۰ مأموریت دارد و از پنل Owner قابل فعال/غیرفعال، افزودن، حذف، ویرایش و جستجو است. رادیوی خراب در این نسخه وجود ندارد.
